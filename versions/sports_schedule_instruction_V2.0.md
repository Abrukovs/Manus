# Sports Schedule Instruction V2.0

V2.0 действует с 2026-10-27.

Главный критерий отбора — хорошие шансы на успех, а не обязательный value-перевес. Value является бонусом. Разрешено публиковать согласованный исход при подтверждённых участниках, однозначном рынке, коэффициенте не ниже 1,50 и отсутствии существенного конфликта источников, даже если модельный перевес не доказан.

Обязателен пул из нескольких матчей каждого доступного вида спорта: теннис, хоккей, баскетбол. Для каждого кандидата проверяются все применимые рынки: теннисный ML и общий тотал геймов; хоккейный 2-way ML с ОТ/буллитами, 3-way regulation ML при наличии и общий тотал; баскетбольный ML и общий тотал с учётом ОТ. Отсутствие хоккейного 3-way рынка не блокирует 2-way ML.

Выбирается максимум два варианта из разных матчей с указанием уверенности и рисков. Ставки не совершаются. Отчёт сохраняется по дате и синхронизируется с GitHub только после создания и проверки файла.
