# Sports Schedule Instruction V1

Сохранённая версия перед переходом на V2.0. Расписание: ежедневно в 05:00 по московскому времени; отдельная задача с GitHub-синхронизацией отчёта.

Ключевая логика V1: анализировать теннис, хоккей и баскетбол, обязательный охват нескольких матчей каждого доступного вида спорта, проверять официальное событие, линию, модель и составы; минимальный коэффициент 1,50; в хоккее 2-way ML с ОТ/буллитами не блокируется отсутствием 3-way regulation рынка; выбирать максимум два варианта из разных матчей.
